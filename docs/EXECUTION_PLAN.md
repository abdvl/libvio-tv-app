## S01 具体拆分

1. 建立 `com.libvio.tv` 的最小原生工程，沿用 Olevod 已验证的构建版本，不移入账号、凭据、签名密钥和更新仓库设置。
2. 用已观察的详情→HD7/HD2 首集路径做数据输入，保留 `routeId` 与 `internalId` 两种身份。
3. 将 `player_aaaa.url` 视为不透明输入，验证每种 `from` 的真实解析方法；解析结果不得写入日志或长期存储。
4. 如试验 WebView 解析桥，完成网页 JS 运行、正确正片识别、获取必要头信息、停止网页媒体并移交 Media3、释放 WebView 的完整过程。失败就明确该 provider 暂不支持，不能以网页能播宣称 TV 已适配。
5. 对两条源分别记录：解析结果类别、首帧、时长、持续播放、暂停恢复、±30 秒、后台恢复；仅保留去敏摘要。
6. 通过后再大规模移植界面，避免先完成所有页面却发现主要线路无法原生播放。
