# LIBVIO TV v0.1.2 · 同线路软件解码

首次正式发布。保留 Olevod 的电视遥控器布局与淡蓝色主题，无需登录，历史和收藏保存在本机。

- 不支持的原生视频格式先尝试同一线路的 libVLC 软件解码，失败后才按同集匹配其他线路。
- 修复 BD1 / HD3 的解析及无 m3u8 后缀的 HLS 清单识别。
- 保留暂停状态、进度和速度；收藏可再次打开并续播。
- 修复软件播放切换全屏时可能提前结束、误跳下一集的问题。
- 支持入口发现与手动换站、多播放源选择、分类、筛选、搜索和本地记录。

## 安装包

- `libvio-tv-v0.1.2-armeabi-v7a.apk`：32 位 ARM，包括本次验证的 Chromecast。
- `libvio-tv-v0.1.2-arm64-v8a.apk`：64 位 ARM。
- `SHA256SUMS.txt`：两个正式签名安装包的校验值。

最低 Android 8.0 / API 26；部分 HD2 HEVC 源的解析需要 Android 11 / API 30 以上。包名 `com.libvio.tv`，versionName `0.1.2`，versionCode `4`。

此前 `0.1.x-dev` 使用调试签名，本次为独立正式签名，无法直接覆盖调试版。需保留本地收藏和历史时请保留原安装，先安排数据迁移；不要通过卸载来尝试覆盖。后续同一正式签名的版本可覆盖升级。

## 验证与范围

本版播放实现已在 Chromecast 验证原 HD3 第 01 集软件解码、连续一分钟输出、暂停/跳转/换源、全屏切换和收藏续播；首页《海洋奇缘：启航》已验证原生 HLS 输出。32 位 ARM 的软解配置优先保证流畅，可能出现更明显的压缩块。尚未完成整集长播、全站格式、所有网络故障组合或主观音画同步验收。
